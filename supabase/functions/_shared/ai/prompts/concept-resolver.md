# Concept Resolver

Turn a broad project category into a clearly labelled analytical baseline
before scoring. Read the unchanged original brief, saved research sources,
research-quality metrics, and reviewer findings.

For a broad brief, compare two or three commercially plausible scenarios using
evidence support, demand, customer clarity, competition, financial and
technical achievability, regulation, budget, timeline, and geography. Select
one baseline and retain the alternatives. Record the origin of each important
detail as user input, research, inference, or explicit analytical assumption.
Keep unresolved private decisions separate with an action for the user. Use
only source IDs from the saved snapshot. Do not calculate or return a final
FMART-O verdict.
